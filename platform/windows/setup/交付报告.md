## 三、架构要点（对应用户需求）

1. **双击装**：exe 检测 `HKCU\Software\HuFu\InstallDir`（权威）/`Run\HuFu`→有且目录有效=升级，锁目录跳过目录页（无痕覆盖：绝不注销 TIP/不动语言列表/跳过 ctfmon 刷新）；无→默认 `%LOCALAPPDATA%\Programs\HuFu` 用户选。野残留（注册在目录亡）→预清死 TIP 键走首装路径+提示。
2. **装完重启**：腾位（`.oldN` 同卷改名）或升级→NeedRestart 引导重启；RunOnce `HuFuPostBoot` 开机清 `.oldN`（幂等）。快速启动（R10）对 PFRO 的影响留真机定论项。
3. **一次重启无残留、新版全功能**：旧 PE 全 `.oldN` 化→postboot 删；SystemIME 残留由 install.ps1 提权段/卸载脚本自带的 `HuFu.old*` 清理链覆盖；注册由 install.ps1 一次性重建（UAC 一次）。
4. **数据全保留（铁律：用户财产零改动，2026-10-13 用户三轮定稿）**：**覆盖安装时 `码表\` 整目录零写入**（不覆盖/不补缺/不复活已删方案）；**`数据\` 全部条目只补缺**——缺失的补上，已存在的一律不覆盖（反查/注释/拆分/转换词典/音效/皮肤/config 皆是用户可自行维护的表，"备份后覆盖"也不做）；`模型\`、`码表导出\`、`用户调整.txt` 永不入包永不被删。全新安装全量落盘。装完设置即生效。代价：版本间词典修正不随升级推送（用户目录用户做主）。
5. **卸载（交互口径 2026-10-13 用户定稿：全程最多 3 次点击）**：①系统确认框（第一下，否=直接退出零弹窗）→ ②备份确认（是=已备份开始卸载；否=打开码表文件夹并退出卸载）→ ③完成告知（数据保留位置 + `.old*` 需重启清理 + 是否现在重启：是=`shutdown /r`）。「连数据一起删」不再交互询问，仅 `/PURGEDATA` 命令行。控制面板可见；引擎=uninstall.ps1（提权一次；UAC 拒绝自动回退每用户模式）+ PFRO 挂删 SystemIME 占用残留 + 清虎符专属的默认输入法覆盖（R16 债务修复）；默认保留 `码表/码表导出/数据/模型`。卸载残留 `.old*` → 完成框引导重启收尾。
