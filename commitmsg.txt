动效v6·S4：皮肤动效节点+门退役（HUFU_BALL→motion.ball）

开关三层化：
- HUFU_BALL=1 强制开 / =0 强制关（逃生舱，显式优先）
- env 未设：皮肤 /skin/motion/ball=true 开（出厂皮肤无此键=1.5.9
  行为——用户按皮肤自助启用，不影响存量）
- 皮肤结果缓存进 BALL_ON_RUNTIME（AtomicBool，show 每帧刷）——
  wndproc/hide 等无皮肤上下文的路径经 ball_gate() 读同一真值

参数化（皮肤 motion 节点，show 每帧读=换肤即时生效）：
- ball_size：球径（6-64，默认 22）
- ball_win：球窗边长（24-160，默认 48）
- observe_ms：观察窗（0-3000，默认 500）
- idle_ms：球驻留（500-60000，默认 4000）
球色沿用 back_color（环）/hilited_back_color（芯）。

皮肤启用示例（皮肤 json 顶层）：
  "motion": { "ball": true, "ball_size": 22, "observe_ms": 500,
              "idle_ms": 4000 }

验收：
- 关门（env 未设+皮肤无键）：1.5.9 纯净（v6 行=0）✓
- 开门（env=1 冒烟）：球驻留 3201px→退场渐隐→纯底 2908 ✓

v6 四步全部落地（S1 球形态 / S2 展开一体感+三根修 / S3 退场渐隐
+尺寸钉死 / S4 皮肤化）。遗留：用户空闲时段跑 s2diag6/wdiag6 复核
fsp 连打与帧序列。
