方案Schema

方案 = 码表目录。切换后立即生效，最近方案对可用 Ctrl+M 来回切。
码表文件夹里新建方案目录后点「刷新列表」即可出现（与本地目录实时同步）。

拼音反查方案选择

任何方案启用反查时都从这里调用；表中放新 .txt 文件后重开设置页即可选择。选「（关闭反查）」后按引导键将直接上屏右侧所选符号。
【` 引导打特殊字】要把 `` ` `` 用作特殊字引导（起段编码），需把 `` ` `` 加入「输入与候选 → 编码字母表」并关闭反查（上方方案选「（关闭反查）」）；反查启用时 `` ` `` 始终是反查引导键。`` ` `` 起段时查方案里的超集副表（按内容自动识别：全部编码以 `` ` `` 开头的 .txt，文件名任意，无需任何提示或设置）。

拆分显示选择

配合「输入与候选 → 显示拆分」开关使用；表中放新 .拆分 文件即可扩展。

输入与候选Input & Candidates

全部图形化配置，实时热更新——不需要碰任何 YAML 或 Lua 文件。

通用

输入

默认 27 码元

候选

全键盘图形化编辑：任意键（含 Caps/Tab/空格/Shift/F 区）设「有候选时 / 无候选时」两套功能（如 [ 有候选直出？、无候选直出！）。支持冲突检测与一键恢复默认。改完全局生效（含整句模式），重启保留。

标点与外观

音效

编码 / 选词 / 上屏 / 翻页 四类提示音（数据\音效\ 下可替换 wav：key.wav、select.wav、commit.wav、page.wav）。

繁简与 Emoji

开启简→繁后打简出繁：候选与上屏文本直接转为繁体，候选顺序不变（无简繁之分的字保持原样原位）。Emoji 注解候选追加在尾部（😊 标记）。数据\转换词典\ 放 OpenCC txt 对照表（STPhrases/STCharacters/TS…/emoji）。

剪贴板上屏

在白名单进程里按 Ctrl+Shift+V 直接把剪贴板文本插入光标处（走输入法通道，不经系统粘贴，密码框类应用可定向关闭）。

整句模型Sentence

当前安装未携带整句模型（轻量安装）
现在各方案（含当前默认的码表方案）可以正常打字；要启用整句组句，请按下面步骤补装模型：
1. 到 GitHub 模型发布页 下载 模型.7z；
2. 解压后把「模型」文件夹整个复制到本输入法安装目录（与「安装.bat」同级——注意是整个文件夹，不是单个文件）；
3. 在「方案」页切换到 虎整句 方案即可整句输入（模型随切换自动加载，无需重启；Ctrl+M 可在两个方案间切换，Ctrl+Alt+H 打开本设置页）。
