# 发布页写法（用户定稿 2026-10-07）

## 结构（固定四段 + 收尾）

```
## 新增
- **功能名**：一句话说清干了什么、默认值/开关方向

## 修复
- 按主题归并成条（如「挂件四连」「加词三连」），不逐条流水账

## 调整
- 行为变化、下线项、机制项

## 整句模型（可选下载）
1. 下载 [default.7z](https://github.com/LeafHW/hufu-ime-rust/releases/download/%E6%A8%A1%E5%9E%8B/default.7z)（约 496MB，见「模型文件」发布页）
2. 解压后把**「模型」整个文件夹**复制到虎符安装目录——与「安装.bat」同级（整个文件夹，不是里面的文件）
3. 约 2 秒自动装载，切到整句方案即可用，**无需重启**
4. 事后随时拖入：「模型」文件夹里任意 `.bin`（整句）/ `.gguf`（重排）自动探测装载，文件名不限

安装：解压后运行「安装.bat」。完整历史见包内 更新日志.txt。
```

## 规矩

1. **覆盖面 = 上一个 release 到本次的全部更新日志条目**，逐条核对，漏了要挨骂（候选右键菜单那次）。
2. **简洁**：主题归并、粗体关键词打头；正文控制在 ~1300 字符内。
3. **终态口径**：被后续推翻的条目只写最终语义（如「顶标并账」→「符号拆条」；防吃二/三/四阶合并成一条）。
4. **无模型段必带**：模型直链 + 目录位置 + **无需重启**（旧模型页写的「要重启」已过时，别抄它）。
5. 资产名惯例：`HuFu-IME-vX.Y.Z-nomodel.zip`（ASCII，中文会被 GitHub 洗掉）。
6. 发布方式：无 gh CLI，用 `git credential fill` 取令牌走 REST API（见发布脚本段）。
7. 发布完自检：正文条目关键词 grep 一遍（右键调频/加词/腾位/150ms…），资产名/大小/状态终验。
