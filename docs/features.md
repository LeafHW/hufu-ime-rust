# 虎符 HuFu · 功能总览

> 本页为 README「主要功能」的明细版。功能速览见 [README](../README.md)。

| 能力       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 虎码整句   | 整句输入为核心；码元与最大码长按方案配置，支持最大码长顶屏、唯一候选上屏、空码清屏等独立开关 |
| 多码表格式 | HuFu 原生、Rime dict.yaml（columns/import_tables/encoder）、多多（---config@ 头、`#固`、`=>`）、QQ五笔、虎整句 `码 词 词`、符号/注释/拆分/反查/补充语料 |
| 方案管理   | 方案=目录；一键切换最近方案对；每方案独立用户词              |
| 整句输入   | 支持 TigerClaw TCSKNM03 五阶模型，兼容 TCSKNM02/04 三阶模型，beam search 组句、置信前缀提前上屏、补充语料 Aho–Corasick 奖励；**Qwen3 GGUF 神经重排已接入**（后台工作线程优先使用进程内 llama.cpp 原生 DLL，失败回退纯 Rust GGUF/Qwen；结果由轮询或后续按键应用）；**整句权重可调** |
| 候选交互   | 数字/分号/引号/自定义选重键、翻页、竖排/横排、调序、置顶、软删、延时显示；**鼠标滚轮缩放字号**（悬停候选框滚动 ±1，范围 10–36，记忆）；**左键拖动移位、右键锁定/再次右键解锁**；**Shift+标点/数字出 Shift 形态**（Shift+,→《、Shift+'→智能配对引号、Shift+1→！，空态与候选态一致） |
| 语言栏菜单 | 中/英切换；右键菜单提供设置、方案切换、打开方案文件夹、导出码表与按键音效开关；码表修改保存后由后台监视器自动重载 |
| 反查       | 默认 `` ` `` 引导，可选全拼/自然码/小鹤双拼等反查表；自然码/小鹤缺独立表时可由全拼基表派生；注释显示拼音/Unicode 分区/拆分 |
| 符号系统   | 快符 `;a`–`;z`、一简符号、`/xx` 分类符号、动态变量（日期/时间/星期）、`\` 命令空间、**`\calc` 真计算器**（+ - * / % ^ 括号，全角符号兼容，上屏纯数值）、**`\w` 造词**（Rime encoder 规则构码，选词自动入用户词库） |
| 繁简与注解 | OpenCC txt 对照（简↔繁、emoji 注），候选滤镜链：前 3 候选自动追加繁体（⚑繁）与 emoji（😊）变体，设置界面开关+方向可选 |
| 用户数据   | 用户词四态（加/隐/权/序）、追加式调整日志、按时间戳导出      |
| 云同步     | WebDAV（坚果云等）双向同步所选方案文件夹与可同步设置，按文件修改时间处理新旧，支持回收站恢复；云端文件为明文，保存在用户自己的 WebDAV 网盘，应用凭据保存在本机 |
| 皮肤       | JSON 皮肤（颜色、布局、圆角、透明度与阴影；Windows 使用 Direct2D/DWrite，旧毛玻璃/玻璃材质按半透明兼容，不提供背景模糊）+ **.ssf 皮肤（搜狗主流格式）**；兼容导入 weasel/squirrel 配色。macOS 的 NSVisualEffectView 前端仍为未发布的开发骨架 |
| 设置界面   | 本地 HTTP Web UI（daemon 托管），当前 `settings-app` 由 Windows WebView2 外壳打开 `/next?shell=1`，旧 `settings-ui` 根页保留；全图形化：方案/候选/键位/整句权重/皮肤编辑器/用户词管理/导入导出。**不碰 yaml/lua** |
| 中英切换   | Shift / Ctrl+Space / Caps / 跟随系统；中文态英文标点；大小写保留混输 |
| 音效       | 4 类按键音 + 音量（可选）：引擎按键即出标签（key/select/commit/page），DLL waveOut 播放（管道取 base64 音频，音量 0–100，PCM 8/16 位 WAV），设置界面开关+试听；默认音源 TigerClaw sounds（KeyNormal/KeySpace/KeyPop/KeyFunc） |
| 数据安全   | 全量用户数据快照导出（配置+用户词+调整日志，ISO 日期时间戳）；HTTP BOM 容错 |
