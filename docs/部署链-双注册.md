## 每次改 DLL 后的完整部署清单

1. 腾位 + 编译：`target\release\hufu_tsf.dll` → `.oldNN`，`cargo build --release -p hufu-tsf`
2. 同步打包源 `E:\DSH-KF\hufu-发行\打包源\hufu_tsf.dll`
3. 同步安装目录 `D:\HUFU\HuFu虎符输入法-v1.4.8-无模型\`
4. **UAC 提权覆盖 `C:\Windows\SystemIME\HuFu\hufu_tsf.dll`**（Start-Process powershell.exe -Verb RunAs；DLL 被加载中先腾位 .oldN）
5. 用户重启目标应用；**验证=枚举进程模块路径 + DLL 时间戳**（编译了≠部署了）

## 教训

2026-09-08 之前 7 项 DLL 修复全部只更新了 target\release 与打包源，
SystemIME 路径从未更新——edge 等系统进程一直跑 9 月 7 日旧版；跟打
器走 target\release 但重启前也跑旧文件。「编译+腾位+打包源同步」不
等于已部署，必须双路径覆盖 + 进程模块级验证。
