# assets — Linux 端随仓库资源包

虎符 Linux 前端（fcitx5）所需的全部数据资源（**模型除外**）。
安装脚本默认从这里装配，无需任何外部下载：

```sh
platform/linux/install.sh          # 码表 + 注释/拆分/反查/符号/音效 全部取自本目录
```

目录与安装布局同构（对应 `~/.local/share/hufu/` 下的同名结构）。

## 内容

| 目录 | 内容 |
|---|---|
| `码表/虎码字词/` | tigress 单字+词（import 闭包 ≈250k 条）、快符/常用符号/一简符号、补充语料 |
| `码表/虎码单字/` | tiger 单字表（≈117k 条）+ 符号 |
| `码表/多多B/` | 多多格式常用字词/生僻字（格式回归与备用方案） |
| `数据/注释/` | `拼音.注释`（字→拼音）、`unicode.注释`（字→Unicode 分区名） |
| `数据/拆分/` | `虎码.拆分`（字→部件拆解） |
| `数据/拼音反查/` | `拼音.txt`（全拼反查） |
| `数据/转换词典/` | OpenCC 简繁表 + emoji 表 |
| `数据/音效/` | 四类按键 wav（`key/select/commit/page`） |

**各文件来源、版本与许可**见 [`../docs/asset-sources.md`](../docs/asset-sources.md)；
**安装 / 资源获取 / 卸载步骤**见 [`../docs/linux-install.md`](../docs/linux-install.md)。

## 说明

- **模型不在仓库**：ngram 整句模型与 Qwen3 重排模型体积过大，单独分发；
  缺模型时引擎为纯码表模式（仅无整句/重排）。
- 安装脚本也支持外部源覆盖（便于换版本）：
  `--from <虎码资源目录>`（码表）、`--tigerclaw <虎爪资源包>`（注释/拆分/反查/符号/音效）。
