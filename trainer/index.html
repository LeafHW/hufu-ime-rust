01 / 它是什么 · WHAT IT IS

一个窗口，
把练习拉回真实输入。

跟打器是虎符的独立窗口程序（Win32 / Direct2D），随虎符安装和升级。正文里贴着一个 2×2 物理像素的 RichEdit 输入宿主——你打出的每个字都经过真正的 TSF 上下文和候选窗，而不是网页里模拟出来的按键。

真输入

组字、选重、上屏，都算数

走真实 TSF 与候选窗，选重按输入法实际成功的选择动作计数：分号、引号、数字、自定义选重键都支持，整句锁词立即记账。

真码表

练的就是你在用的那套

分析走本机虎符服务，依据当前方案已保存的码表、用户调整与全局个人表，再结合候选配置。不另建一套练单词库，也不调在线分析。

真数据

记录留在本机

练习数据在 %LOCALAPPDATA%\HuFu\trainer，与安装目录分开。窗口大小和位置会记住；升级和普通卸载都保留练习记录。

看着舒服

读正文不费眼

默认 1280×800 窗口，正文 36 DIP、行高 1.66，字号 10–100 可调。字体优先霞鹜文楷，没装就回退微软雅黑，界面与正文同族。

02 / 打开 · OPEN

三种打开方式。

  1. 设置里开虎符设置 → 跟打器 → 打开启用开关 → 点「打开跟打器」。
  2. 老板键默认 Ctrl+Alt+G 打开 / 隐藏。可在同页录制、保存或清除，改完重新注册，不用重启服务。
  3. 开始菜单「HuFu 虎符跟打器」，或直接运行独立 EXE。

关闭开关只会停用虎符内置启动入口和老板键，练习数据仍然保留；已经开着的窗口也能继续用。

03 / 一段 · A ROUND

粘贴文章，
首键开始计时。

复制一段文章或整篇群文，在跟打器里 Ctrl+V 或 Alt+E 直接载入。整篇群文会自动去掉标题、难度与段号尾行；载入本身不计为打字成绩。

  1. 载入Ctrl+V / Alt+E 从剪贴板取正文，格式自动识别。
  2. 计时真实首键开始；空格、回车按正文输入处理。
  3. 结算打完本段给九项成绩，可重打或直接进下一段。
  4. 切段Ctrl+← / Ctrl+→ 前后段；Esc 关闭面板或中止本轮。

05 / 提示 · HINTS

该提的词，
提前摆在正文里。

文章模式支持词提。F1 → 词提 → 提示设置 里可以分别开关词提、编码、选重数字与词组着色；策略选「最短编码」或「词组优先」，也可以开启按连续正确进度重算的动态词提——策略在开打后锁定，中途不会变。

  • 一简词
  • 简码
  • 二字三码
  • 二字全码
  • 三字全码
  • 长词全码
  • 六档词色。六档各自配色，另有通用提示色与词底色；选重 1～10 可以单独配色，正文和 F10 同步生效。首选不标数字，二选起才标。
  • 顶栏「编码」。显示光标处下一个字的单字编码；有下一级候选时带上选重尾键，无码或段末显示「—」。
  • F10 全文编码。逐词列出全文编码，标点保持中立、不单列编码行，并与前词一同换行；与正文共用同一套六档分类和配色。
  • 理论分析。码长、选重与缺字汇总，附主键区理论热力图——按词条编码统计理论按键次数，不当作实际击键记录。
  • 来源即新知。保存码表或用户调整后，后台检查会自动刷新正文词提和已打开的 F10，通常约 1 秒，不用换文重打，成绩也不丢。
  • 服务不可用也能练。提示和理论分析会显示状态，独立输入与记分照常。

07 / 边界 · LIMITS

先说清楚边界。

  • 只有 Windows 端内置；Linux、macOS 暂时没有。
  • 本地「赛制」只是规则冻结与记账，不代表晴杯认证成绩。
  • 暂不支持晴杯报名、加密成绩提交、排行榜上传、每日字数同步与阅读进度回写。
  • 发群与读群走 QQ 的 UIA 可读内容；QQ 更新或权限差异可能让读取、发送不可用，这时可以手动复制群文或粘贴剪贴板。
  • 字数按 Unicode 标量算，组合音标和 ZWJ emoji 可能被算成多个字符。
  • 正文是自绘排版，与手写分行、装饰纹理等极端样式不可能像素级一致。
