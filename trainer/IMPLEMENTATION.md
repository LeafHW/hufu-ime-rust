# 虎符跟打器实现与验证记录

更新：2026-11-08。本轮按原设计 HTML、CSS、说明及九屏截图重做界面，位于分支 codex/hufu-trainer。未替换现用服务、注册 DLL、安装或发布；旧预览的大小、哈希及验收结论不适用于本轮。

## 本轮实现

默认 1280×800 DIP、正文 36 DIP、行高 1.66；使用系统字体：优先霞鹜文楷家族，未安装回退微软雅黑（正文与界面同族，不再嵌入字体），数字/编码使用等宽字体。修复重复系统标题栏，训练宿主为贴随正文光标的可见 2×2 物理像素 RichEdit，维持真实 TSF 上下文。

九屏分别落实：S1 独立统计、正文提示与分段轨；S2 独立居中行、前后组淡化、逐字提示及组进度；S3 来源侧栏、解析预览和显式编辑；S4 列表与详情；S5 控制区与实时预览；S6/S7 完整主视图；S8 身份优先与按需登录；S9 规则和完整双栏清洗预览。详细对照及首轮历史见 DESIGN-AUDIT.md。

- F2 → 本地文库可选五份内置练单语料，整份字表能推进后续组。
- 模态背景采用 7 DIP 的内部 D2D 模糊，失败降级为暗色遮罩。窗口级透明/磨砂仍禁用，以保证原生输入兼容。
- 当前段速度、键准、击键、码长统一用本段范围，整场指标供赛报使用。时间读取单调时钟，首字未提交时也显示实际用时。
- 结算区分字准与晴 Pro 键准；两键两错可能为键准 100%、字准 0%、有效速度 0。未改既定公式。
- 编辑文章后即时更新字数；旧模型版本的原生控件不能覆盖新草稿。规则状态切换保留草稿，异步身份结果不重建其他面板。
- 设置独立「跟打器」页新增持久化启用开关、打开按钮与可录制全局老板键（默认 Ctrl+Alt+G）。关闭停用虎符内置启动入口和老板键，保留数据；已有窗口及独立 EXE 仍可使用。源码与设置前端已热更新到 D:\HuFu；2.1.0 安装包尚未重打。
- 旧服务缺 API 时明确提示更新完整包并重启。词库超限有独立词提不可用原因，不再让整个状态接口失败；逐字/词级缓存区分。

## 保留边界

- 未登录真实在线账号、未发送 QQ 消息；对应 QQ 版本和个人书架权限未完整联调。在线限登录、分类/书架读取与取文，不含晴杯报名/认证提交、排行榜上传、每日字数或阅读进度回写。
- 本地赛制不代表晴杯认证。成绩操作只复制，由用户核对目标并手动发送。
- 无真实历史来源的排名、上次差值显示空态；慢字为当前段上屏时间组均摊估计，不冒充逐字精确计时。
- 手工分行、装饰纹理、字重光晕、动态细节与 DirectWrite 实际排版仍有差异，不声称像素级一致。
- 字数按 Unicode 标量，组合音标和 ZWJ emoji 可能为多个字符；未覆盖全部 DPI、多显示器及所有第三方输入法组合。
- E 盘目录完整性标签会影响服务管道连接，交互预览写到正常 Documents 目录；它不解释旧版布局偏离。
- 升级/普通卸载保留数据；异常退出恢复文章和已完成分段，当前未完成段重新计时。SSF 无可靠配色时保留当前主题并提示。
- 正文/界面字体用系统已安装的霞鹜文楷家族（按优先级探测，未安装回退微软雅黑），不再随包分发字体与 OFL/NOTICE 文件；练单语料附 Apache 2.0/NOTICE，见 licenses/ 与 drills/NOTICE.md。
