# 虎符内置跟打器

独立 Win32 / Direct2D 程序，真实 RichEdit 接收输入，与虎符安装和升级集成。
原生平台与统计底座来自本工作区疾风项目；新增能力在此维护，原疾风目录保留。
默认逻辑窗口为 1280×800；使用系统字体：优先霞鹜文楷家族，未安装回退微软雅黑，不再随 EXE 嵌入字体。
正文默认 36 DIP、行高 1.66，数字与编码采用等宽字体。

构建：`powershell -File trainer/build.ps1 -Release`，或
`cargo build --release --locked --target x86_64-pc-windows-gnu --manifest-path trainer/Cargo.toml`。

数据默认位于 `%LOCALAPPDATA%/HuFu/trainer`，与安装目录分离。

新版虎符在「设置 → 跟打器」独立页启用开关，再点击「打开跟打器」，或按
默认全局老板键 `Ctrl+Alt+G`（可在同一页录制/保存/清除）打开。关闭开关会停用
虎符内置启动入口与该快捷键，保留练习数据；已打开的窗口仍可继续使用，也可通过
开始菜单「HuFu 虎符跟打器」或独立 EXE 打开。
本轮源码与设置前端已热更新到本机安装位（`D:\HuFu`）；`HuFuSetup-2.1.0`
安装包仍是旧构建，重装前需按发行铁律重打安装包。

跟打器可独立练习；实时编码提示通过本机虎符服务取得，不调用在线分析服务。
服务未运行时正文输入和统计仍然可用。提示依据当前码表、用户调整与候选配置；
无法确认实际可达的编码不显示。整句模型的预测结果不作为静态编码提示。
开启整句模式时，动态候选顺序无法由静态码表保证，词提会明确提示暂不可用。

成绩包含本轮规则、正文指纹、是否清洗/粘贴、是否完成等信息。练习与赛制分开；
赛制关闭提示、粘贴和失焦暂停。引号同类等价默认开启，可在开打前配置，开打后冻结。
清洗仅在显式操作时应用，原文保留可恢复。QQ操作提供读取与复制，发送前由用户核对。

首次使用可 Ctrl+V 直接载入剪贴板文章，或从「更多 → 本地载入」打开 TXT、本地语料与单字表。
练单入口为「更多 → 本地载入 → 单字与词组练习」；可选常用单字前/中/后五百、前1500单字
及常用词组前三百。按真实首键开始计时；空格和回车在练习中作为正文输入，完成后用于进入下一段。
Ctrl+V / Alt+E 载入剪贴板文章，不把整篇粘贴当作输入成绩。

成绩中的「字准」反映正文对错；「键准」沿用晴 Pro 的击键、回改和退格公式，
两者含义不同。有错时有效速度按错一罚五计算，同时保留裸速。
字数采用 Unicode 标量口径；文件的 CRLF / CR 在训练正文中统一为 LF，原文另存。
热力图统计当前段练习中按下的物理键，只画主键区（Esc/F 行 + 字母数字区），
键帽上的数字是该键按下次数；不含界面快捷键（Ctrl+←/→、Ctrl+V、Alt+E、F 区）
和按住产生的自动重复。

文章、分段成绩和配置支持恢复；进程退出后未完成的当前段重新开始，避免把进程外
的时间算成有效训练。升级和普通卸载保留用户数据。

在线登录不保存密码；登录令牌由 Windows DPAPI 保护并绑定服务地址。
切换服务或退出登录会使在途请求失效。网络失败或身份过期会明确显示状态，
已经取得的文章仍可保留预览与载入；过期身份需重新登录才能继续受认证限制的请求。
QQ 仅读取明确选定且正在打开的当前会话，不自动切群、按 Enter 或发送消息；
会话列表按 UIA 类名词级匹配，置顶会话与当前选中会话都会出现在列表中（2026-11-10 修复），
同名会话保留重复、读取时仍会校验目标。QQ 更新可能使 UIA 读取失效，此时可手动复制群文，
通过剪贴板载入。
在线功能支持登录、分类、书架读取与取文；暂不支持晴杯报名、加密成绩提交、
排行榜上传、每日字数同步或阅读进度回写。本地「赛制」是规则冻结和本地记账，
不代表晴杯认证成绩。成绩按钮只复制文本，由用户手动发送。

训练输入由贴随正文光标的可见 2×2 物理像素 RichEdit 宿主接收，以维持 TSF 输入上下文；
正文仍由 DirectWrite 绘制，界面不另设显眼的底部输入栏。
当前窗口采用不透明背景，磨砂/透明材质选项已禁用并说明原因；模态层的背景模糊
只处理程序内部页面，不是桌面透视或窗口级毛玻璃。
SSF 皮肤无法取得可靠配色时保留当前主题，并显示提示。
没有采集到的历史比较、排名、慢字数据或群统计会显示空态；不填入样例数字。
