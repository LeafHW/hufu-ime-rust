# 虎符内置跟打器

独立 Win32 / Direct2D 程序，使用真实 RichEdit / TSF 输入宿主，与虎符安装和升级集成。
原生平台与统计底座来自本工作区疾风项目；新增能力在此维护，原疾风目录保留。
默认逻辑窗口为 1280×800，正文默认 36 DIP、行高 1.66，数字与编码使用等宽字体。
字体优先使用系统已安装的霞鹜文楷，未安装时回退微软雅黑，EXE 不内嵌字体。

构建：`powershell -File trainer/build.ps1 -Release`，或
`cargo build --release --locked --target x86_64-pc-windows-gnu --manifest-path trainer/Cargo.toml`。
PowerShell 仅用于开发构建脚本；产品运行时不启动 PowerShell、cmd 等解释器。
正式打包使用仓库的 `发行脚本/release.ps1`，版本与双产物验收以本次发行报告为准。

数据默认位于 `%LOCALAPPDATA%/HuFu/trainer`，与安装目录分离。
窗口大小与位置会保存并在下次启动恢复；显示器变化时会将窗口调整到可见工作区。

在「虎符设置 → 跟打器」启用开关后，可点击「打开跟打器」，或按默认全局老板键
`Ctrl+Alt+G` 打开/隐藏。老板键可在同页录制、保存或清除，修改后重新注册，无需重启服务。
关闭开关会停用虎符内置启动入口和该快捷键，保留练习数据；已打开的窗口仍可继续使用，
也可通过开始菜单「HuFu 虎符跟打器」或独立 EXE 打开。

## 练习与界面

首次使用显示空练习状态，点击主窗口「从剪贴板载入」或按 Ctrl+V / Alt+E 可直接载入文章。
本地载入仅保留剪贴板动作，TXT 文件、内置单字/词组练习及载入面板已移除；在线取文和 QQ 群功能保留。
按真实首键开始计时；练习中的空格、回车作为正文输入，完成后可进入下一段。
尚未载入文章时不计时、不记成绩。载入整篇剪贴板文本不计为打字成绩。

文章模式不显示词提；兼容恢复旧单字会话的字编码与选重提示。提示与理论分析使用本机虎符服务，
依据当前码表、用户调整和候选配置，不调用在线分析服务；无法确认可达的编码不显示。
服务不可用时仍可独立输入和记分，提示与理论分析会显示相应状态。

## 成绩与规则

成绩记录九列为：用时 / 重打 / 段号 / 速度 / 击键 / 码长 / 键准 / 打词 / 字数。
用时显示为 `0:06.4`，完成后保留重打、下一段入口，不再打开独立成绩页。
成绩单设置保留自动行为、标准/简洁/经典/完整/自由编辑样式、模板和最近成绩预览。
成绩单已移除「字准」，旧字段与模板会迁移；保留键准，正文对错判定仍用于练习和成绩计算。
键准沿用晴 Pro 的击键、回改和退格口径；有错时有效速度按错一罚五计算，同时保留裸速。

成绩包含规则、正文指纹、是否清洗/粘贴与完成状态。练习与赛制分开；赛制关闭提示、
粘贴和失焦暂停。引号同类等价默认开启，可在开打前配置，开打后冻结。
清洗只在显式操作时应用，原文保留可恢复。字数采用 Unicode 标量口径，训练正文统一换行符，
原文另存。文章、分段成绩与配置支持恢复；重启后未完成的当前段重新开始，避免计入进程外时间。
升级与普通卸载保留用户数据。

## QQ 与在线发文

绑定群后，F2 可发送当前文章；在线取文进入跟打区时会自动发到已绑定群。
「打完一段自动发成绩」由选群页左下复选框控制，不另设手动发成绩按钮。
发送使用剪贴板、激活 QQ、校验当前会话、粘贴与回车；目标失效或无法校验时中止，内容留在剪贴板。
会话列表按 UIA 类名词级匹配，支持置顶条目和当前会话，同名条目不自动合并。

发送在后台执行，避免等待 QQ 时阻塞末字上屏与结算，并限制同一时间只发一条。
粘贴/回车后尝试在消息区确认；消息区无法读取时采用有界等待，之后才回切跟打器并恢复输入焦点，
不重复粘贴。该确认依赖 QQ 的 UIA 可读内容，不代表对远端送达的独立验证。
QQ 更新或权限差异可能使读取/发送不可用，此时可手动复制群文或粘贴剪贴板内容。

在线功能支持登录、邮箱验证码注册（60 秒冷却）、分类与取文。注册成功后自动登录。
切换服务或退出登录会使在途请求失效；身份过期会显示状态，需重新登录才能继续认证请求。
已取得的文章可继续练习。暂不支持晴杯报名、加密成绩提交、排行榜上传、每日字数同步或阅读进度回写；
本地「赛制」表示本地规则冻结与记账，不代表晴杯认证成绩。

## 账号与配置同步

本机在线登录态写入 `online-auth.dpapi`，由 Windows DPAPI 保护，并绑定服务地址。
另外，跟打器会生成供虎符云同步使用的 `profile.json`，包含配置、晴账号、保存的登录密码和登录态；
此 profile 为明文，经用户配置的 WebDAV 同步，不受本机 DPAPI 文件的保护。
因此不再使用“在线登录不保存密码”的旧说明。

profile 作为跟打器独立文件同步，不出现在云同步方案列表中；只有启用虎符云同步并配置好 WebDAV
时才联网同步。启动时按实际文件时间选择配置，首次启动也可导入已有 profile。
账号导入要求服务地址一致，并且同步 profile 比本机登录态新；本机已有较新的登录态不会被覆盖。
显式退出标记优先于同步账号，即使旧 DPAPI 文件尚未删除也不自动恢复已退出的账号。
退出晴账号或切换服务会清除 profile 中的口令与会话，登录/注册仅保存对应成功请求的口令。

跟打器运行期间下载的配置会保留在磁盘；普通保存只合并本机实际改动，避免用旧界面覆盖远端更新，
下次启动时采用同步配置，不在打字途中强制改动当前练习。窗口位置属于本机显示器布局。
profile 损坏或暂时同步失败会提示，仍可使用有效的本机设置练习。
普通练习不要求启用 WebDAV，具体同步结果与冲突状态以虎符同步界面反馈为准。

## 实现与验证范围

正文由 DirectWrite 绘制，2×2 物理像素 RichEdit 宿主贴随正文光标维持 TSF 上下文；
原生宿主闪烁光标隐藏，正文只显示自绘光标，不另设底部输入栏。
窗口使用不透明背景；外观页不提供已退役的磨砂/透明材质。SSF 无可靠配色时保留当前主题并提示。
未取得的历史比较、排名、慢字或群统计显示空态，不填样例数字。

`crates/gale-app/examples/design_review.rs` 调用实际 D2D 绘制生成布局样本。
样本内原生编辑字段由 D2D 代绘，不能替代真实键盘、TSF、QQ、网络或持久化验证。
历史实现与验收记录见 [IMPLEMENTATION.md](IMPLEMENTATION.md)，正式包以当次发行验收为准。
语料来源与授权见 [drills/NOTICE.md](drills/NOTICE.md) 和 `licenses/`。
内部 crate 名沿用 gale，交付程序名为 `hufu-trainer.exe`。
