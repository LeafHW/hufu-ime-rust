# 跟打统计口径与成绩单格式

适用范围：`trainer/crates/gale-core`（stats.rs 统计产线、score.rs 成绩单产线）。
蓝本：晴跟打 Pro（`_research/typesunny-stats.md`）、疾风1代（jifeng records.jsonl）、
州州跟打器（双口径对照）。本文是该对照表的单一事实源，代码注释引用本文。

## §1 计数字段（stats.rs 产线定义）

| 字段 | 定义 |
| --- | --- |
| 字数 | 当前已比较的 Unicode 标量数（中途停止不计尚未输入的正文） |
| 总键数 | WM_KEYDOWN 串行口径（is_stat_key 区段表：字母/数字/符号/空格/回车/退格全计；组字中的键同样计入） |
| 上屏键组 | 每次 IME commit 记一组（并击口径，需输入宿主在 commit 时回调） |
| 回改 | 物理退格删除已上屏字符的次数，不论此前对错（compare.rs） |
| 错字 | 比对不匹配的上屏字符数 |
| 退格 | 组字退格 + 废码罚账 − 取消退格（composition_backspaces + waste_keys − cancelled_backspaces） |
| 废码 | 组字编码被取消的次数；取消时该轮组字全部键数计入退格（晴 Pro 空上屏分支） |
| 选重/标顶 | 输入宿主按候选序号数字键上屏（选重）/ 顶屏（标顶）计数 |

## §2 计算公式

| 指标 | 公式 | 口径 |
| --- | --- | --- |
| 速度 | 字数 / 用时分钟 | 各家一致 |
| 击键 | 键数 / 用时秒 | 各家一致 |
| 码长 | 键数 / 字数 | 各家一致 |
| 键准（产线） | (键 − 回改 − 退格×2) / (字数 + 回改) × 字数 / 键 × 100% | **晴 Pro 精确口径**，ScoreRecord.accuracy 直接取该值 |
| 键准（对照） | (键数 − 退格 − 回改 − 错字) / 键数 × 100% | 疾风1代简化式，仅存 `accuracy_simple` 字段做回归对照，**非产线** |
| 有效速度 | max(0, 速度 − 错字×5/分钟) | 晴 Pro「错一罚五」GetValidSpeed |
| 键准钳制 | [0, 100] | 分母为 0 时取 100 |
| 州州对照 | zz_speed / zz_speed2 / zz_mc 单列 | 州州 ComputeStats 直译，不与晴口径混用 |

## §3 成绩单格式（score.rs format_score_report）

对齐晴跟打 Pro 报告串逐字节口径（research-digest §C.3/C.4），发成绩/赛报共用：

- 各项**双空格**连接、标签与数值间无空格（`击键5.12`）；末项恒为签名 `虎符跟打`；
- 段号：文来 mark 含 `-`（如 `2-277101`）用 `段{mark}`，否则 `第{mark}段`；
- 速度：无错字 `速度{裸速}`；有错字 `速度{罚后}/{裸速}` 双数字，**无数值括注**
  （晴按 token 解析，括注会错位）；
- 字准**不进成绩单**（晴字段集无此项，字准留 UI）；
- 字段顺序：速度 → 击键 → 键准% → 码长 → 字数 → [难度] → 用时 → 错字 → 退格 →
  废码 → 选重 → 标顶 → 回改 → 总键数 → 赛制标记 → 签名；
- 难度有数据才输出（`难度普(1.84)`，无分数值则 `难度普`）；
- 赛制标记：`【赛制】` / `【非赛制】` / `【非赛制】[词提开]`（词提开的练习必须可甄别）；
  可再附 `·未完成` / `·清洗` / `·粘贴`；
- 用时裁到厘秒**截断不四舍五入**，去前导 `00:`（`1:23.45`；1h+ 为 `1:02:03.45`）；
- **不含尾换行**：单条复制与整场赛报逐行拼接都不会出现空行（消费方自行补 `\n`）。

样例（2026-11-08 当前产线格式）：

```text
第1段  速度58.33/61.25  击键5.12  键准97.44%  码长2.00  字数58  难度普(1.84)  用时0:56.72  错字1  退格3  废码2  选重1  标顶0  回改2  总键数116  【赛制】  虎符跟打
第2段  速度61.25  击键5.40  键准99.12%  码长2.09  字数52  用时0:50.94  错字0  退格1  废码0  选重0  标顶0  回改1  总键数109  【非赛制】[词提开]  虎符跟打
段2-277101  速度55.10  击键4.98  键准96.88%  码长1.96  字数60  难度难(2.31)  用时1:05.44  错字2  退格4  废码1  选重2  标顶0  回改3  总键数118  【非赛制】·清洗  虎符跟打
```

## §4 有效性门槛（is_valid）

`ScoreRecord::is_valid` / `SegmentStats::is_valid`（score.rs 常量）：

- 字数 ≥ `VALID_EFFECTIVE_CHARS`（10）且 用时 ≥ `VALID_EFFECTIVE_MS`（10s）；
- 语义：进入速度/键准等**有效指标聚合**（今日汇总、赛报均值）的最小段；
- 与「<5 字聚合硬门」（RaceSummary::from_records / daily_summaries 里段数过滤）
  是两道独立的门：<5 硬门只拦段数统计混入超短段，is_valid 拦全部二分指标。
